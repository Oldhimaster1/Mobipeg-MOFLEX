02 Make it yours

Video format

Standard 2D · MOFLEX layout 6

Fast mode reduces motion-search work at the same quantizer. Image quality and file size can change. Advanced subme overrides take precedence; verification stays enabled.

Framing & crop ＋

Crop margins use even input pixels, applied separately to each eye for SBS. Aspect crops are centered after manual margins and respect each eye’s pixel aspect ratio. Letterbox / Fit keeps the cropped picture with borders; Fill crops again to the output frame. Stretch changes proportions. Preview before converting.

Above 400×240 or 30 fps is experimental for 3DS playback. Stereo encodes two eye frames per displayed frame. More pixels and frames increase memory and encoding time.

Fine-tune your encode ＋

Applies to size-targeted movie ranges. Scene-aware analysis takes a little extra time; uniform keeps the previous allocation.

A size limit may require up to 9 complete trial encodes. Lower quantizer values preserve more detail.

Advanced ＋

Blank parameters inherit the selected profile. Custom hqdn3d coefficients replace Image treatment; unspecified coefficients become 0 (FFmpeg may derive automatic coefficients). Layout, sample rate, pixel format and timestamp mapping follow the MOFLEX pipeline.

Subme 1 is excluded because it desynchronizes this codec. Overrides can increase runtime and file size; physical 3DS playback is not certified.
